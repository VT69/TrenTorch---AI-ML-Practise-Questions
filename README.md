# Vaibhav Tiwari Resume

LaTeX resume matching placement and ATS-safe guidelines.

## Prerequisites
- `pdflatex` (TeX Live or MiKTeX)
- `latexmk`

## Building Locally
Run `make` to compile the PDF. The output will be in `out/main.pdf`.
Run `make clean` to remove auxiliary files.

## Overleaf
You can ZIP this entire directory and upload it directly to Overleaf. It will compile out of the box using `pdflatex`.
