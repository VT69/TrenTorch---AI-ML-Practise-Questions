# TrenTorch - AI & ML Practise Solutions

My solutions to [TrenTorch](https://trentorch.com/) practice problems — machine learning built from first principles, implementing real PyTorch signatures from scratch and passing hidden test suites.

Every accepted submission is **auto-pushed** to this repo, so it doubles as a running log of what I've practised.

Each problem lives in its own folder:

```
DL/softmax-fwd-bwd/
├── solution.py      # My accepted solution
└── README.md        # Difficulty, link to the problem, my notes
```

## ⚙️ How it works

1. I solve a problem on TrenTorch and submit it.
2. Once it passes all hidden tests, the solution is committed automatically.
3. It's filed under its topic folder with a commit like `Add: softmax-fwd-bwd (Medium) — DL`.
